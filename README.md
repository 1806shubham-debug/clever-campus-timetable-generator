# Clever Campus Timetable Lab

Build a full-stack Intelligent College Timetable Optimization System. Create the requested research-oriented platform for managing faculty, subjects, rooms, availability and constraints; generate and compare Greedy, Backtracking and Genetic Algorithm timetables with fitness/conflict/execution metrics; include dashboard, management pages, generator, timetable viewer, algorithm analysis and research analysis. Use the supplied Neo-Brutalist Swiss editorial SaaS direction: warm #F3EFE6 background, black borders/sidebar, square layouts, yellow/blue/red/purple accents, uppercase bold typography, data-heavy charts/tables. Enable Lovable Cloud for persisted data and make the app polished, responsive, and functional with usable demo data.
